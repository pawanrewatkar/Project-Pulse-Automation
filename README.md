# Project Pulse Automation

A **web UI automation project** for testing the **Project Pulse** application using **Java and Selenium WebDriver**.

The project focuses on automating key application workflows and validating core functionality through structured and maintainable test cases.

### 🛠️ Tech Stack

**Java | Selenium WebDriver | TestNG | Maven | POM**

### ✨ Key Coverage

* User & workspace management
* Project and task management
* Subtasks and recurring tasks
* Comments, attachments & documents
* UI functional validations
* Regression test scenarios

### 🎯 Purpose

Built as a **practical QA automation project** to demonstrate real-world web application testing, framework practices, and maintainable automated test development.

**Focus:** Reusable automation • Functional Testing • Regression Testing • Maintainable Test Design
